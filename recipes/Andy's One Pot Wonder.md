# Ingredients
- .5 lb? sausage
- 1.5-2 lb chicken thigh?
- 24oz tomatos
- beans
- onion
- peppers?
- zuchini
- spinach, asparagus, random herbs
- garlic
- 1 tbsp cumin, 1 tbsp coriander, smoked paprika
# Instructions
- brown onions
- add sausage, render
- add garlic
- add spices
- add chicken, brown
- add zuchini, peppers
- add tomatos plus < can worth of water, simmer 15 mins
- add spinach, asparagus, herbs
- add beans last - 5 mins
